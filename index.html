복음서듣기

마태오·마르코·루카·요한 복음을 장별로 듣는 Android 앱

Google Play Console URL — 마케팅(기본) 페이지로 이 주소(index.html)를 사용하세요. 지원·개인정보는 아래 링크를 각각 등록합니다.

앱 소개

가톨릭 한국어 성경 복음 4권, 총 89장의 오디오를 스마트폰에서 들을 수 있습니다. 복잡한 메뉴 없이 복음 선택 → 장 선택 → 재생에 맞춘 단순한 화면입니다.

오디오는 앱에 포함되어 있어 인터넷 없이 재생할 수 있습니다. Android 8.0(API 26) 이상을 권장합니다.

TalkBack 안내

사용 방법

  1. 복음 선택 — 상단 그리드에서 마태오·마르코·루카·요한 중 하나를 탭합니다.
  2. 장 선택 — 장 목록에서 장을 탭하면 재생·정지·이어 듣기가 전환됩니다.
  3. 재생 바 — 하단 재생 바로 재생·정지·이어 듣기를 제어합니다.
  4. 연속 재생 — 한 장이 끝나면 같은 복음의 다음 장이 자동으로 이어집니다.
  5. 마지막 장 — 복음의 마지막 장이 끝나면 1장부터 다시 재생됩니다.
  6. 수면 타이머 — 30·60·90·120분 후 자동 정지 또는 「계속」을 선택합니다.
  7. 이어 듣기 — 앱을 다시 열면 마지막 위치에서 이어 들을 수 있습니다.

주요 기능

  • 4복음 89장 전체 오프라인 오디오
  • 장 완료 후 다음 장 자동 재생 · 마지막 장 후 1장 루프
  • 재생 중인 장 목록 강조 표시
  • 정지 후 같은 장 위치에서 이어 듣기
  • 백그라운드·화면 꺼짐 상태 재생
  • 수면 타이머 (30 / 60 / 90 / 120분)
  • TalkBack(스크린 리더) 음성 안내
  • 개인정보 수집 없음 — 개인정보 처리방침
