복음서듣기

가톨릭 성경복음을 듣는 Android 앱

앱 소개

마태오·마르코·루카·요한 복음을 장별로 선택해 들을 수 있습니다. 이동 중이나 잠들기 전처럼 성경을 펼치기 어려울 때도 말씀에 귀 기울일 수 있도록 단순한 화면과 재생에 집중했습니다.

Android 8.0(API 26) 이상에서 이용할 수 있습니다.

작동법

  1. 복음 선택: 상단 2×2 그리드에서 마태오·마르코·루카·요한 중 하나를 탭합니다.
  2. 장 선택: 장 목록에서 장을 탭하면 재생·정지·이어듣기가 전환됩니다. 재생 중인 장은 목록에서 강조됩니다.
  3. 재생·정지: 장 목록 아래 재생 바를 탭합니다. 재생 중이면 정지, 정지 상태이면 이어 듣기 또는 선택한 장 재생입니다.
  4. 수면 타이머: 복음 그리드 아래 타이머 바를 탭해 30·60·90·120분 또는 「계속」을 고릅니다. 설정한 시간이 지나면 재생을 자동으로 멈춥니다.
  5. 이어 듣기: 앱을 다시 열면 마지막 위치 「이어서 ○○장 재생」 제안이 나타날 수 있습니다.
  6. 백그라운드 재생: 화면을 끄거나 다른 앱으로 이동해도 재생이 계속됩니다. 알림 표시줄에서 재생 상태를 확인할 수 있습니다.

주요 기능

  • 4복음서 중 원하는 복음과 장 선택 후 재생
  • 선택한 장부터 복음 끝까지 연속 재생
  • 지금 재생 중인 장을 목록에서 쉽게 확인
  • 정지 후 재생 시, 가능한 경우 이전에 듣던 위치에서 이어 듣기
  • 백그라운드·화면 꺼짐 재생: 잠금 화면·다른 앱 사용 중에도 듣기 계속
  • 수면 타이머: 30·60·90·120분 뒤 자동 정지 또는 「계속」 선택
  • 오프라인 재생 (앱에 포함된 오디오 파일 사용)
  • 개인정보 수집 없음 (개인정보 처리방침)
